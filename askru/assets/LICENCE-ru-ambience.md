## Why this file exists

The founder asked for *"free wala Google se utha le"*. Most audio a search
returns is **not** free for commercial use, and this app takes money, goes
through payment-gateway review, and sits in an investor data room. A takedown
on a shipped app is an app update, not an apology. So the licence was read on
the page rather than assumed, and it is written down here next to the file so
the next person does not have to re-derive it.

## What was done to the original

| | Original | Shipped |
|---|---|---|
| Size | 15.3 MB | **3.4 MB** |
| Channels | stereo | mono |
| Bitrate | 256 kbps | 56 kbps AAC |
| Duration | 7:59 | 7:59 (uncut) |
| Mean volume | −26.9 dB | **−20.1 dB** |

🔴 **It was made LOUDER on purpose, and that is not a mistake.** The original
is already very quiet. Played at the 18% the app uses, it would have landed
near −42 dB — effectively inaudible on a phone speaker. Worse, an unnormalised
source means **"18%" means something different for every track**, so swapping
the music later would silently change how loud the app is. Normalising to a
known −20 LUFS is what makes the founder's "15 to 25% max" an actual rule
instead of a number that happens to suit one file.

Stereo → mono: at this volume nobody can hear the image, and it halves the
download. 256 → 56 kbps for the same reason.

The track is **not cut**. It is music with sitar, tabla and chant rather than
a drone, so a loop point chosen by arithmetic would be audible. It plays
through and repeats.
